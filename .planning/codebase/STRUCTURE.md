# Structure

- `fish_speech/text`: text normalization and token preparation.
- `fish_speech/models/text2semantic`: semantic-token generation.
- `fish_speech/models/dac`: audio codec components.
- `fish_speech/inference_engine`: model and reference orchestration.
- `tools/server`, `tools/webui`, and root API/client scripts: serving and UI surfaces.
- `docs/`, `docker/`, and configuration directories: user guidance and deployment material.
- Existing untracked `src/` and `tests/` remain untouched.

Sources: repository tree and README.md.
