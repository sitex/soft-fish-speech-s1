# Цель
Fish Speech (OpenAudio S1) — open-source многоязычная модель text-to-speech с поддержкой клонирования голоса. Проект предоставляет инструмент для синтеза речи на основе текста с эмоциональным окрашиванием и контролем параметров. Это вендоренный клон проекта https://github.com/fishaudio/fish-speech, используется для локальной разработки и экспериментов.

## Критерии готовности
- [ ] Модель OpenAudio-S1 успешно загружается и выполняет инференс
- [ ] Поддерживаются основные режимы: text-to-speech, voice cloning
- [ ] Интеграция с локальным окружением (gradio UI, REST API) функциональна

## Политика ответов
- Водитель сам решает: обновления чекпоинтов, эксперименты с параметрами инференса, улучшения скорости обработки.
- Эскалировать человеку: обновление зависимостей, смена архитектуры модели, merge PR с upstream, деплой.

## Ограничения
- **Язык/платформа**: Python 3.10+, PyTorch 2.5.1+, требует GPU для эффективного инференса.
- **Лицензия**: Code — Apache 2.0; модели — CC-BY-NC-SA-4.0 (не коммерческое использование).
- **Upstream**: fishaudio/fish-speech — push НЕ делать (вендор). Обновляются только экспериментальные ветки/чекпоинты локально.
- **Зависимости**: Строгие версии (numpy ≤1.26.4, modelscope==1.17.1, pydantic==2.9.2) — конфликты частые.
